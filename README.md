# -Amazon-Sales-Analysis---PowerBI
Sales Analysis Dashboard using PowerBI
Amazon Sales Dashboard | Power BI

📌 Project Overview
The Amazon Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. It provides insights into sales performance, order trends, product categories, payment methods, order fulfillment, and geographical sales distribution.

The main objective of this project is to analyze Amazon sales data and help businesses understand sales trends and make data-driven decisions.

🎯 Project Objectives
- Analyze overall sales and order performance.
- Track key performance indicators (KPIs).
- Understand product category and product-level performance.
- Analyze payment methods and order fulfillment.
- Identify sales trends and geographical performance.
- Monitor cancellations and returned orders.

🛠️ Tools & Technologies
- Power BI – Dashboard development and visualization
- Power Query – Data cleaning and transformation
- DAX – Calculated measures and KPI calculations
- Microsoft Excel – Dataset preparation and data analysis

📊 Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Units Sold
- Total Profit
- Profit Margin
- Return Order Percentage
- Cancellation Order Percentage

📄 Dashboard Pages
1. Overview – Displays key sales metrics and overall business performance.
2. Category & Products Analysis – Analyzes sales by product category and individual products.
3.Order Status – Displays the distribution of orders by their current status, helping analyze completed, cancelled, returned, and pending orders to understand overall order performance.
4. Payment, Fulfillment & Geography Analysis – Examines order distribution across payment methods.Provides insights into order fulfillment, returns, and cancellations.Analyzes sales performance across geographical regions.

🔍 Key Features
- Interactive dashboard with page navigation.
- KPI cards for quick performance monitoring.
- Dynamic charts and graphs.
- Category-wise and product-wise sales analysis.
- Payment method and fulfillment analysis.
- Geographical sales insights.
- Data-driven business performance reporting.

💡 Business Value
This dashboard helps users understand sales performance, identify high-performing products and categories, monitor order issues, and discover opportunities to improve business operations.
